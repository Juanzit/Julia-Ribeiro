# Julia-Ribeiro — no.vazio

Portfólio visual autoral, fotografia e criação audiovisual de **Júlia Ribeiro**.

## Conceito
> *"meu trabalho vem do olhar atento aos detalhes, às atmosferas e texturas, carrego no olhar, sensibilidade e escuta, utilizando com luzes e cores ou a ausência delas. sempre guiada por um sentido."*

- **Direção de Arte & Ensaio:** `no.vazio`
- **Formação:** Cinema e Animação — Universidade do Estado de Minas Gerais (UEMG) & Administração
- **Local:** Belo Horizonte, MG — Brasil

## Tecnologias
- HTML5 Semântico
- Tailwind CSS
- CSS3 Moderno (Filtros fotográficos, transições e animações)
- JavaScript Nativo
- Modern Web Guidance (Lightbox com `<dialog>` nativo e acessibilidade)
